# План защиты — 5 минут

Это заметки для подготовки презентации; окончательные слайды можно сделать после Stop Coding. Включать только фактически полученные результаты, связанные с SHA финальных весов.

## 0:00–0:40 — постановка

Четыре независимые цели 128×128 на четырёх расстояниях. Нужно получить одну фазовую маску. Качество оценивается по четырём реконструкциям: SSIM — основной показатель, Pearson — дополнительный; также важна задержка синтеза.

## 0:40–2:00 — нейросетевой метод

Показать схему: совместный ResUNet → четыре комплексных поля → точные слои Френеля → обучаемое объединение с пространственной и Fourier-ветвями → две нейросетевые коррекции → один фазовый PNG. 2.995 млн параметров в текущей конфигурации.

Объяснить: модель с самого начала видит весь комплект. Физика сообщает, как предсказанное поле распространяется. Поправки обучаются end-to-end, жёсткого шага GS и оптимизации конкретной маски при применении нет.

## 2:00–2:50 — обучение и проверка

В малом эксперименте 400/50/50 комплектов, проверены точные и записанные source/group пересечения. Loss: 1−PCC + 1−SSIM + 0.1 amplitude MSE, вспомогательный loss промежуточных стадий. Лучшие веса выбираются на validation, test в этом выборе не участвует. Для основного результата честно назвать фактический кластерный датасет и его разбиение.

## 2:50–4:10 — результаты

Если сдаётся текущий проверенный checkpoint: сеть PCC 0.6449, глобальный SSIM 0.5294; GS200 PCC 0.7093, SSIM 0.5124. Новой независимой финальной выборки после разработки ещё не было. Сеть улучшила обе метрики относительно v1; против GS выигрывает по среднему SSIM, уступает по PCC.

Привести несколько заранее определённых комплектов, включая слабый результат. Показать сохранённые ДОЭ и восстановленные изображения. Наложения между глубинами сохраняются — это ограничение метода.

Время: T4 41.42 мс, CPU-сеть 969.85 мс, CPU GS 2220.49 мс по медиане прогретого синтеза. Отдельно указать устройства, dtype и отсутствие I/O/загрузки модели в этих числах. Не называть 53.6× преимуществом на одинаковом оборудовании.

Если финальные веса другие, заменить цифры на измеренные для них или прямо подписать приведённые числа как предыдущий малый эксперимент.

## 4:10–5:00 — сдаваемый продукт и ограничения

Docker запускается без скачивания весов или ручной установки библиотек. Пять комплектов обрабатываются в одном процессе с одной загрузкой модели, результат — один 8-bit Grayscale PNG на комплект. Закончить конкретным достигнутым качеством и скоростью, без обещаний непроверенного улучшения.

## Ответы на вероятные вопросы

- **Есть ли внутри GS?** Нет. Есть физическое распространение и обучаемые сообщения/поправки. Целевая амплитуда не подставляется по правилу GS; после сети классический синтез не запускается.
- **Зачем физика?** Для переноса предсказанных комплексных полей и дифференцируемой оценки реконструкций, а не для восстановления маски классическим алгоритмом.
- **Что дали отдельные блоки?** Измерен совокупный эффект совместного энкодера, ширины, Fourier-ветвей и scheduler. Отдельная абляция не выполнена.
- **Почему SSIM выше, а PCC ниже GS?** Метрики оценивают разные свойства. Наш глобальный SSIM учитывает средний уровень, контраст и ковариацию; его рост не означает исчезновение паразитных изображений.
- **Почему несколько стадий допустимы?** Стадии сами являются обучаемой нейросетью; организаторы разрешили несколько проходов и физические слои. Формальный допуск определяют эксперты.
- **Можно ли воспроизвести PNG?** Да: веса и конфигурация в репозитории, код фазы опубликован, Docker не требует сети при применении.
