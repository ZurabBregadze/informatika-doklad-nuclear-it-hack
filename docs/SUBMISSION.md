# Финальная сдача

Репозиторий: https://github.com/ZurabBregadze/informatika-doklad-nuclear-it-hack

## До 09:30 — решение целиком

1. Получить выбранный на validation checkpoint от обучения на кластере. При основной метрике SSIM использовать лучший validation SSIM. Если новые веса не готовы или не проверены, в комплекте уже есть рабочие веса малого эксперимента; описать фактически сдаваемый вариант.
2. Из корня проекта выполнить `python export_weights.py /path/to/best_ssim.pt`. Проверить `weights/model.json`: эпоху, архитектуру, SHA, fingerprint датасета.
3. Пересобрать Docker командой из README. Запустить пять комплектов. Проверить, что получены пять PNG 128×128, 8 bit, Grayscale. Убедиться, что контейнер выполняется с `--network none`.
4. Загрузить исходники, Dockerfile, requirements, README и **оба файла** `weights/model.pt` / `weights/model.json` в GitHub. Не отправлять только ссылку на Google Drive и не заменять `.pt` Git LFS-указателем.
5. Дождаться успешного GitHub Actions `Docker inference`. Зафиксировать итоговый commit SHA. Сверить содержимое репозитория с реально проверенным Docker-контекстом.
6. До 09:30 отправить ссылку и требуемые материалы по форме организаторов. Сама форма в сообщении не указана; репозиторий не заменяет отправку формы.

После 09:30 не изменять код, Dockerfile, зависимости и веса. Результат большого обучения нельзя незаметно подменить после Stop Coding: это часть решения.

Для сборки локального ZIP сдачи выполните `python package_submission.py`. Получится `hackathon_submission.zip` с файлами в корне архива; датасет, кэши и исходные рабочие checkpoint в него не входят. Перед загрузкой в GitHub ZIP нужно распаковать: Dockerfile должен быть в корне репозитория, а не оставаться внутри ZIP.
